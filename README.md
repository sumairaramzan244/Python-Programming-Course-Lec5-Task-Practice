## Lecture 5 Task — Student Report Card in Python  
In this practice task, I built a Student Report Card program in Python. The program takes student details as input and automatically assigns a grade based on the marks entered by the user.  

---

## What I Learned  
* `input()` function is used to take input from users like  Name, Class, Roll Number and Marks from the user  
* f-string is used to display student information in a clean and formatted way  
* `int()` casting is used to convert marks from string to number for comparison  
* `if`, `elif`, and `else` conditions are used to assign grades based on marks obtained  
* Grade A is given for 90 and above, B for 80+, C for 70+, D for 60+, and F for below 60  
* `\n` escape sequence is used to add empty lines for better output formatting
